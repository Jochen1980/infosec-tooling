# Verpflichtung auf die Informationssicherheit gemäß des ISMS der de.NBI Cloud Bielefeld

>Version 1.0 vom 28.05.2021

Die de.NBI Cloud Bielefeld umfasst Beschäftigte, denen 
sensible Daten, Unterlagen und sonstige Informationen der de.NBI Cloud oder auch ihrer 
Kunden oder Geschäftspartner zugänglich sind. Eine unbefugte Weitergabe an 
Dritte könnte zu einem wirtschaftlichen Schaden bei der de.NBI Cloud Bielefeld oder den betroffenen 
Kunden oder Geschäftspartnern führen.
Desweiteren haben Beschäftigte der de.NBI Cloud Bielefeld administrativen Zugriff auf Systeme
der Cloud, weshalb eine Einhaltung der Vorschriften des ISMS der de.NBI Cloud Bielefeld stets
geboten ist. Der/Die Beschäftigte wurde über die Wichtigkeit insbesondere der folgenden
Vorschriften informiert:

- [Informationssicherheitsleitlinie](../informationssicherheitsleitlinie.md)
- [Richtlinie zur Klassifizierung und Kennzeichnung von Informationen](../richtlinien/Klassifizierung_Kennzeichnung_von_Informationen.md)
- [Richtlinie und Verfahren zur Informationsübertragung](../richtlinien/Informationsuebertragung.md)
- [Richtlinie für eine aufgeräumte Arbeitsumgebung und Bildschirmsperren](../richtlinien/Arbeitsumgebung_und_Bildschirmsperren.md)
- [Richtlinie zum Gebrauch von kryptographischen Maßnahmen](../richtlinien/Gebrauch_von_kryptographischen_Maßnahmen.md)
- [Richtlinie für den zulässigen Gebrauch von Werten](../richtlinien/Gebrauch_von_Werten.md)
- [Richtlinie für mobile Geräte](../richtlinien/Mobile_Geräte.md)
