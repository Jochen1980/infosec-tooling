## Ziel dieser Arbeitsanweisung

Bevor neue Software zum Einsatz kommt, muss die unterliegende Lizenz der Software
betrachtet werden. Dadurch sollen geistige Eigentumsrechte der Entwickler geschützt und
juristische Konsequenzen, insbesondere durch das Urheberrecht, vermieden werden.

## Anwendungsbereich

Die Arbeitsanweisung gilt für alle Mitarbeiter von ADM und BRF für
die de.NBI Cloud Bielefeld.

## Beschreibung

Bevor neue Software zum Einsatz kommt, muss die unterliegende Lizenz der Software betrachtet werden.
Es sollte überwiegend OpenSource-Software zum Einsatz kommen, welche Lizenzen verwenden, die von der
[Open Source Initiative](https://opensource.org/licenses) eine Zustimmung finden.
Dabei sind folgende Lizenzen als geeignet zu nennen:

- Apache License 2.0
- BSD 3-Clause "New" or "Revised" license
- BSD 2-Clause "Simplified" or "FreeBSD" license
- GNU General Public License (GPL)
- GNU Library or "Lesser" General Public License (LGPL)
- MIT license
- Mozilla Public License 2.0
- Common Development and Distribution License
- Eclipse Public License version 2.0

Bei der Verwendung von Software mit diesen Lizenzen sind die inhaltlich geforderten Klauseln einzuhalten.

OpenSource-Software ist immer ClosedSource-Software vorzuziehen.

Wird Software mit einer oben nicht genannten Lizenz verwendet, so muss überprüft werden, ob die
Lizenz im Umfeld der de.NBI Cloud Bielefeld verwendet werden darf.

Wird kommerzielle Software verwendet, so muss diese mitsamt Laufzeit im ISMS 
[protokolliert](../aufstellungen/lizenzen.md) werden.
